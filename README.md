Project Title: Student Grade Calculator

Project Description
The Student Grade Calculator is a simple and user-friendly web application designed to help students calculate their weighted average based on their subject grades and percentage weights. 
It allows users to add and delete subjects, view their weighted scores, and determine whether they meet the passing grade.

The system features a responsive design that works on mobile phones and computers. It is built using HTML, CSS, and JavaScript without requiring a database or external libraries.
 Features:
- Add Subjects – Enter subject names, grades, and percentage weights.
- Calculate Weighted Average – Automatically calculates the final grade based on subject grades and weights.
- Passing Status – Displays whether the student meets the passing grade of 75.
- Subject Management – Add and delete subjects easily.
- Input Validation – Checks grades and weights to prevent invalid entries.
- Weight Validation – Ensures that the total subject weight equals 100%.
- Grade Guide – Displays grade ranges and their corresponding descriptions.
- Sample Grades – Provides sample data for testing the calculator.
- Reset Function – Clears all subjects and student information.
- Responsive Design – Works on mobile phones, tablets, and computers.
- Simple Interface – Uses a clean pink-and-white theme for an attractive user experience.

 Technologies Used:
 HTML5 – Structures the webpage and its content.
 CSS3 – Styles the interface, layouts, colors, and responsive design.
 JavaScript – Handles calculations, input validation, subject management, and interactive features.

 How to Use:
1. Open the Student Grade Calculator website.
2. Enter the student's name (optional).
3. Enter a subject name, grade, and percentage weight.
4. Click Add Subject.
5. Repeat until all subjects are added.
6. Make sure the total weight equals 100%.
7. Click Calculate Grade to view the weighted average and passing status.
8. Click Reset All to start over.
 
Project Purpose:
This project aims to provide students with an easy and convenient way to calculate their weighted grades, monitor their academic performance, and understand their final results.
